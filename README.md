# Tavvy

Менеджер групп вкладок Firefox и отдельный браузерный предпросмотр дизайна.

## Расширение Firefox

```sh
npm install
npm run build:firefox
```

В Firefox открыть `about:debugging#/runtime/this-firefox`, нажать
«Загрузить временное дополнение» и выбрать `build/firefox/manifest.json`.
Открывать панель кнопкой Tavvy на панели инструментов. Требуется Firefox 140+.
Временную установку после перезапуска Firefox нужно повторить; данные хранятся
под фиксированным ID расширения. ZIP для передачи: `npm run package:firefox`.
ZIP не подписан для постоянной установки в обычный Firefox.

Работают реальные вкладки текущего окна, создание и переключение групп,
создание/активация/закрытие вкладок, архив и восстановление, вложенность,
перетаскивание и настройки. Вкладки других групп скрываются через `tabs.hide`,
закреплённые остаются общими и не входят в счётчики. Настройка «Выгружать неактивные вкладки» по умолчанию выключена. При включении после переключения выгружаются только скрытые вкладки предыдущей группы без звука; закреплённые и воспроизводящие звук не затрагиваются. При возвращении Firefox загружает выбранную вкладку заново. Группы общие между окнами,
но списки вкладок и активная группа независимы для каждого окна.
Настройка «Закреплённые вкладки по группам» по умолчанию выключена. При её включении закреплённые вкладки относятся к активной группе каждого окна. Firefox не позволяет скрывать закреплённые вкладки, поэтому Tavvy временно открепляет их перед скрытием и закрепляет обратно при возвращении. Перед отключением или удалением расширения выключите эту настройку, чтобы восстановить закрепление всех вкладок.
Удаление группы переносит её вкладки в «Основную» и сохраняет дочерние группы.
«Основную» удалить нельзя. Существующие вкладки при первом запуске попадут в неё.

Положение action popup задаёт Firefox. Высота popup ограничена 600px. Приватные окна пока
не поддерживаются. Восстановление архива создаёт вкладку по сохранённому URL:
история переходов, контейнер и данные формы не восстанавливаются. Архив ограничен
200 записями; закрытие целого окна не добавляет каждую его вкладку в архив.
Раздел резервных копий позволяет создавать копии вручную или по расписанию в
подпапке загрузок Firefox. По умолчанию копирование включено раз в день; папку
и частоту можно изменить в настройках. Формат Tavvy содержит группы, вложенность,
вкладки из обычных окон, архив и настройки. Восстановление добавляет данные к
существующим, а вкладки из копии открывает в текущем окне. История вкладок и
данные форм не переносятся; некоторые служебные адреса Firefox не входят в копию.
Страница восстановления также распознаёт JSON настроек Tavvy и бэкапы Simple Tab Groups. Для STG сохраняются названия,
цвета, порядок, пустые группы, ссылки вкладок и закреплённые вкладки. Импорт
добавляет данные к текущим группам, не заменяет их. Повторный импорт одного и того же бэкапа STG
не создаёт дубликаты. Незавершённый импорт можно продолжить повторным выбором файла.
Обычные импортируемые вкладки создаются выгруженными; закреплённые загружаются.
Контейнеры, правила автосортировки и настройки STG не переносятся.
Локальные file:// ссылки сохраняются как вкладки-пояснения с исходным адресом:
Firefox запрещает расширению напрямую создавать вкладку с таким URL.

Интерфейс доступен на английском и русском языках; по умолчанию выбран английский.
Язык переключается в настройках. Переводы находятся в `src/locales/`.

## Предпросмотр

`npm run dev` → http://127.0.0.1:5173.
`npm run build` → открыть `index.html` через файл.
Он использует отдельные демонстрационные данные и не трогает Firefox.
Предпросмотр использует однотонный фон и демонстрационные данные.

## Проверки

```sh
npm test              # сборки, Node/jsdom, модель Firefox API
npm run lint:firefox   # валидатор Mozilla web-ext
npm run smoke:firefox  # настоящий Firefox в отдельном временном профиле
```

Для нестандартного пути задать `FIREFOX_BINARY`. Smoke проверяет реальные
операции над вкладками, фоновые сообщения, storage и взаимодействие интерфейса
с фоновым процессом. Он не использует основной профиль пользователя.

## Структура

- `src/background/` — очередь команд, состояние рабочего пространства, Firefox API.
- `src/extension/` — запуск расширения и постоянная страница импорта.
- `src/domain/` — общие правила и валидация настроек.
- `src/features/` — настройки, drag-and-drop и демонстрационные данные.
- `src/platform/` — индекс Firefox API и адаптер данных предпросмотра.
- `src/ui/` — общий renderer макета и расширения, поиск, виртуализация и навигация.
- `extension/manifest.json` — исходный манифест.
- `styles/` — общие стили, отдельные стили предпросмотра и расширения.
- `scripts/` — сборка, сервер разработки, тест в Firefox.
- `tests/` — проверки Node и jsdom.
- `prototype/` — исходный монолит, не подключается.
- `dist/`, `build/` — генерируемые файлы.

Подробности и источники: [docs/architecture.md](docs/architecture.md).

Нагрузочные проверки: `npm run benchmark`. Результаты оптимизации: [docs/performance.md](docs/performance.md).
